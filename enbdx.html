Problem

Legacy multi-app codebase, long build times, fragmented features, and slow release cycles impacting UX and velocity.

Approach

Feature-based modularization, Hilt DI, Navigation Component, backend-driven UI, and robust CI/CD with automated tests (WebDriverIO + Appium, TDD).

Impact

Builds cut from 40→2 min, faster parallel dev across 5 apps, smoother onboarding with Jumio KYC, and higher release reliability.

Key Contributions

Multi-App Modularization

Restructured into feature/core modules; build time reduced 40m→2m; enabled parallel teams.

Digital Onboarding

Account opening module with Jumio OCR + liveness; backend-driven UI shared across 5 apps.

Modern Android Stack

Jetpack Compose, MVVM, Coroutines, Hilt/Dagger2, Paging2 for scalable, maintainable UI.

Automation & CI/CD

WebDriverIO + Appium, TDD, GitHub Actions, artifact signing, phased rollouts.
